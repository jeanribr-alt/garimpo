Política de Privacidade — Garimpo

Última atualização: 15/11/2026

O Garimpo é uma ferramenta interna de uso privado, usada pelos próprios administradores para pesquisar anúncios públicos e gerenciar as suas próprias campanhas de anúncios no Facebook e Instagram.

Quais dados usamos

Usamos apenas os dados das contas de anúncios, páginas e pixels que pertencem aos próprios usuários do Garimpo, acessados com a autorização deles, para criar e gerenciar campanhas, conjuntos, anúncios e vídeos. Não coletamos dados de pessoas que veem os anúncios.

Como guardamos

Tokens de acesso e configurações ficam armazenados de forma protegida no servidor e não são compartilhados com terceiros. Arquivos enviados são usados só para criar os anúncios e removidos depois.

Compartilhamento

Não vendemos nem compartilhamos dados com terceiros. Os dados só são enviados à Meta (Facebook/Instagram) para criar os anúncios pedidos pelo próprio usuário.

Exclusão de dados

O usuário pode apagar seus dados a qualquer momento removendo o token e as configurações dentro do Garimpo, ou removendo o acesso do app nas configurações do Gerenciador de Negócios da Meta. Pedidos de exclusão também podem ser feitos pelo contato abaixo, e os dados são apagados em até 30 dias.

Contato

Dúvidas ou pedidos de exclusão: pelo e-mail cadastrado como contato deste app na Meta.
